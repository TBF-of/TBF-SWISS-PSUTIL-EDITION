# 🔥 TBF-SWISS — PSUTIL EDITION

> **Swiss Army Knife for Linux/PC — by TBFPUMBA**

A multi‑tool for Linux/PC with 21+ functions. Uses `psutil` for accurate system stats.

---

## 🚀 Features

- 🌐 Network: Ping, Port Scanner, IP Geolocation, DNS, WHOIS  
- 🖥️ System: CPU, RAM, Disk, Uptime, System Info (`psutil`)  
- 🔑 Generators: Password, Hash (MD5/SHA1/SHA256), Base64, MAC, IP, UUID, Random String, QR Code  
- 📥 Download file, Check website status  

---

## ⚡ Installation

```bash
git clone https://github.com/TBF-of/TBF-SWISS-PSUTIL-EDITION.git
cd TBF-SWISS-PSUTIL-EDITION
pip install -r requirements.txt
python3 tbf_swiss_psutil.py
```

---

📦 Dependencies

```bash
pip install requests rich psutil
```
